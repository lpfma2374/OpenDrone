# OpenDrone

Estratégia nacional de drones: sete plataformas, um hub industrial e um fundo soberano.

## Conteúdo

- `index.html` — redirecciona para a landing page
- `OpenDrone.dc.html` — landing page com navegação para todo o dossiê
- `Estrategia Nacional de Drones.dc.html` — documento consolidado, 40 slides
- `Memo OpenDrone_*.dc.html` — sete memorandos de plataforma, duas páginas cada
- `models/OpenDrone_*.html` — sete modelos 3D interactivos (three.js), exportáveis em OBJ e GLB
- `models/img/` — vistas renderizadas usadas nos documentos e na landing page

## Publicar

Site estático, sem build. 

**GitHub**: carregar o conteúdo desta pasta na raiz do repositório.

**Vercel**: importar o repositório e aceitar as predefinições — nenhum comando de build, o directório de saída é a raiz. O `vercel.json` incluído garante o encaminhamento estático.

## Nota sobre os números

Despesa de defesa, mercado global, dados da banca, ANACOM e INE vêm de fontes públicas, listadas no último slide do documento consolidado. Custos de plataforma, dotação do fundo e projecção a dez anos são estimativas de conceito, assinaladas como preliminares.
